# AccesDiary

AccesDiary es un proyecto creado con la intención de implementar y aprender conceptos básicos de JAVA y su conexión con GitHub. Este proyecto maneja el lenguaje JAVA a través de Apache NetBeans.

## Motivación

Mi idea a futuro es ir mejorando este proyecto con todos mis conocimientos actuales y futuros, con el objetivo de realizar un análisis y una comparación de mi desarrollo como programador.

## Objetivo

Desarrollar un gestor de contraseñas completo que incluya:

* Imágenes de usuario.
* Validación de credenciales.
* Mensajes de sistema y ayudas.
* Funcionalidad para ocultar/mostrar contraseñas.
* ¡Y todo lo que pueda imaginar para mejorar la seguridad y la experiencia de usuario!

### ¿Cómo guardarlo?

1. Haz clic en el botón verde **"Add a README"** en tu repositorio.
2. Pega el texto de arriba en el editor.
3. Desplázate hacia abajo hasta la sección que dice **"Commit changes"**.
4. Dale clic al botón verde **"Commit changes"** (puedes dejar el mensaje por defecto que dice *Create README.md*).
